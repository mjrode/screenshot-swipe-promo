How to Add Notes to Photos on iPhone, Including Screenshots

By Michael Rode · September 21, 2026 · 4 min read · How-To

Quick answer: To add a short note to an iPhone photo, open it in Photos, swipe up, and use the caption field. For longer explanations, attach the image to Apple Notes. Use Markup when the words should appear on the picture itself. Screenshot organizers can combine notes with tags and reminders.

You have three screenshots of the same desk. One shows the dimensions, one shows a sale price, and one was the finish you liked. Without a note, all three look like items on the same shopping list.

Which kind of photo note do you need?

Choose the destination before you type. A caption suits a short description you will search later. A note document suits a comparison with several images and links. Visible text on an image suits instructions you intend to send to someone else.

How do you add a caption in Photos?

Open the image, swipe up or tap its information button, and enter your text in the caption field. Apple describes captions as a way to make images easier to find in Search. The photo-information instructions show where that field lives.

Write the detail the picture cannot explain: “Compare this model with the smaller desk before Friday.” Avoid simply describing the obvious object. “Desk” adds less context than “fits the wall beside the window.”

How do you keep a photo inside Apple Notes?

  1. Open or create a note with a specific title, such as “Office desk shortlist.”
  2. Use the attachment button to add a photo from your library.
  3. Write your explanation beside the image and add any useful links.

You can also share an image from another app into Notes and choose an existing note. Apple documents both routes in its guide to photo attachments. This works well when one decision involves several screenshots, a web link, and a few lines of reasoning.

Give the document a title you can recognize in a list. Six notes called “New Note” recreate the same retrieval problem in a different app.

How do you put text directly onto the picture?

Open the image’s editing tools and choose Markup. In the Markup toolbar, use the add button and choose Add Text, then position and format the text box. Apple’s Markup guide covers those controls.

Use this for a label another person needs to see: “Use this entrance” or “Change this setting.” Keep text away from the information it explains. If you need a clean version for another purpose, preserve one before adding annotations.

How can you add context while reviewing screenshots?

Screenshot Swipe puts optional notes, tags, and reminders into the keep workflow. You can explain why a screenshot matters as you review it, then use that context when browsing later. Start with manual notes; AI Smart Review is an optional Pro feature described in the app listing.

Use a three-part note: the item, why it matters, and the next action. For example: “Oak desk, narrow enough for the office, measure the doorway before ordering.” If there is a deadline, set a reminder rather than relying on the words “remember this.”

For categories that recur, add a consistent tag. The note explains the individual screenshot; the category helps collect related ones.

What else should you know?

Can I add a note without writing on the photo?

Yes. Use a caption for a short description or attach the image to a note document for a longer explanation. Choose this approach when you want the picture to remain visually clear. Reserve visible annotations for information that another person needs to see directly on the image.

Will a caption appear when I send a screenshot?

A caption is separate from visible text placed on the image. If your recipient must see an instruction, use Markup or include the explanation in your message. Check the actual item you are sending instead of assuming every sharing destination will carry the same supporting information.

Should I use Apple Notes or photo captions?

Use a caption for a single image with a short explanation. Use a note document when you need several pictures, a list, links, or a longer decision history together. Choose the place you will naturally return to when it is time to use the information.

What should I write in a screenshot note?

Write the context you are most likely to forget: why you saved it, what detail matters, and what happens next. “Compare the annual price before renewal” is more useful than “subscription screen.” Add a real reminder if the next action needs to happen on a particular day.

How can you make your next saved image useful?

  1. Choose a caption, note document, or visible annotation based on where you will use the image.
  2. Write one sentence explaining why you saved it.
  3. Search for it later today and add a reminder if action is due.
